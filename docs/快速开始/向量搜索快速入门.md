# 向量搜索快速入门

向量数据库将非结构化数据（文本、图片、声音）转换成了计算机可以理解和计算的数学形式（向量），并提供了高效的相似性搜索能力。从而支持以图搜图、商品推荐、好友推荐、听歌识曲等业务能力。
