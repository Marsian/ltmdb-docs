# 混合文本检索最佳实践

全文搜索 和 向量搜索 各有其优势和劣势。全文搜索适用于基本的关键字检索和文本匹配，而向量搜索在跨文档语义匹配和深度语义理解方面表现出色，但在短文本查询方面可能缺乏效率。

如果能同时使用这两种检索方式，就能结合其优点进一步提高文本搜索的准确性和速度，以满足用户对精确结果的期望。

本章节介绍基于RSF和RRF两种计算方式的混合文本检索的最佳实践

搜索主要分两部分：

**（1）进行初步的向量搜索筛选，从而做性能优化**

以子查询的形式，计算所有文章的向量与查询向量 query_vec的余弦距离（s_score，距离越小越相似）。 **order by s_score limit 100** ： 按照向量相似度排序，只取出 **最相似的100条记录** ，有效避免了对整个数据集进行昂贵的BM25计算。

**（2）主查询：融合两种搜索的分数**

**分数归一化**：由于BM25分数和余弦距离分数的量纲和范围不同，无法直接比较。代码使用Min-Max归一化将两种分数都转换到 \[0, 1\]的区间内。

**线性加权组合**：将归一化后的两种分数按权重相加。

- BM25权重为0.6：更侧重关键词精确匹配的相关性。
- 向量相似度权重为0.4：也考虑语义相似性。

**最终排序**：根据计算出的最终 score进行降序排列，返回综合相关度最高的5条记录。
